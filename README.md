# Website Uno

A simple multi-page portfolio website showcasing Alexi Trinune's development projects.

## Pages

- `index.html` — Main page introducing Website Uno and linking to the portfolio
- `portfolio.html` — Interactive carousel featuring YTDL and Im Bored project links
- `styles.css` — Shared page and carousel styling
- `portfolio-carousel.js` — Carousel navigation behavior

## Portfolio

The portfolio carousel includes links to:

- [YTDL](https://github.com/AlexiTrinune/YTDL)
- [Im Bored](https://github.com/AlexiTrinune/ImBoredSoIMadeThis)

## Running locally

Open `index.html` in a web browser. Use **Explore My Portfolio** to open the carousel, then use the arrows or dots to switch projects.
