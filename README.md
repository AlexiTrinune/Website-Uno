# Website Uno

A simple multi-page website hosted in this repository.

## Pages

- `index.html` — Main landing page
- `portfolio.html` — Portfolio page
- `styles.css` — Shared website styling

## Portfolio

The portfolio includes a link to the [YTDL repository](https://github.com/AlexiTrinune/YTDL).

## Running locally

Open `index.html` in a web browser. Use the **Open Portfolio** button to navigate to the portfolio page.
